# Detections

This folder contains the Splunk detection rules and SPL searches used throughout the Enterprise Active Directory SOC Home Lab.

## Current Detections

- Successful Logons (Event ID 4624)
- Failed Logons (Event ID 4625)
- Privileged Logons (Event ID 4672)
- Process Creation (Event ID 4688)
- User Account Creation (Event ID 4720)
- Users Added to Privileged Groups (Event ID 4732)
- PowerShell Activity
- Top Security Events
- Top User Logons
